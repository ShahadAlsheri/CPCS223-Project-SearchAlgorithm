# CPCS223-Project-SearchAlgorithm
# Algorithm Search Project (CPCS223 - Algorithm 1)

## Project Overview
This is a Java project that demonstrates different search algorithms on a randomly generated array.  
It generates an array of user-defined size, sorts it using Quick Sort, and allows searching for a key using multiple search algorithms.  
The time consumed by each algorithm is measured and displayed.

## Features
- Generate a random array of integers
- Display the array before and after sorting
- Sort the array using Quick Sort
- Search for a key using:
  - Linear Search
  - Binary Search
  - Interpolation Search
  - Jump Search
- Display the index of the found key (or indicate if not found)
- Measure and display execution time for each search in nanoseconds

## Topics Covered
- Array manipulation
- Random number generation
- Sorting algorithms (Quick Sort)
- Searching algorithms:
  - Linear Search
  - Binary Search
  - Interpolation Search
  - Jump Search
- Measuring execution time (`System.nanoTime()`)
- Control structures (`for`, `while`, `if`)
- User input using `Scanner`
